# ATOSWEB — Landing Page Premium

Landing Page oficial da marca **ATOSWEB**.
> *"Design bonito não basta. Ele precisa gerar **ATOS**."*

---

## ✦ Visão Geral

Projeto focado em criar landing pages de altíssima conversão e impacto visual cinematográfico, com estética futurista, clean, tecnológica e minimalista.

### 🌌 Destaques da Hero Section
- **Cenário Cósmico Imersivo**: Órbita luminosa em loop contínuo com buraco negro/eclipse e marca d'água compositiva em pirâmide "A".
- **Header Inteligente**: Navegação com backdrop blur adaptativo, logo de alta fidelidade e botão CTA com aura neon.
- **Tipografia Geométrica**: Equilíbrio com *Plus Jakarta Sans* e *Outfit*.
- **Totalmente Responsivo**: Layout otimizado para Desktop, Tablets e Mobile.
- **Sem Dependências Pesadas**: HTML5, CSS3 moderno e Vanilla JavaScript puro.

---

## 🛠️ Tecnologias

- **HTML5 Semântico**
- **CSS3 Moderno** (CSS Variables, Flexbox, Grid, Backdrop Filters, Keyframes)
- **Vanilla JavaScript** (A11y, scroll observadores, menu mobile)
- **Google Fonts** (*Plus Jakarta Sans* & *Outfit*)

## 🚀 Como Rodar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/Tiago25792/ATOSLP.git
cd ATOSLP
```

2. Abra o arquivo `index.html` diretamente no seu navegador, ou execute um servidor HTTP simples:
```bash
# Com Python
python -m http.server 3000

# Com Node (npx)
npx serve .
```

3. Acesse `http://localhost:3000`.
